# Как подключить приём заявок и отзывов

Сайт статический: сам по себе он ничего не отправляет и **честно говорит об этом** посетителю, пока адрес
приёма не задан. Когда адрес задан, форма отправляет туда JSON и показывает «Заявка отправлена» только после ответа 2xx.

## 1. Укажите адрес в конфиге

`src/config/site.ts`:

```ts
endpoints: {
  lead: 'https://ваш-сервис.example/api/lead',     // форма записи
  review: 'https://ваш-сервис.example/api/review', // форма отзыва
},
```

## 2. Контракт

`POST <endpoint>`, `Content-Type: application/json`. Ответ **2xx** означает «принято», любой другой код сайт
покажет как ошибку и предложит позвонить или написать письмом.

Заявка (`lead`):

```json
{
  "type": "lead",
  "name": "Ашот",
  "phone": "+374 77 123 456",
  "car": "Toyota Camry, 2015",
  "message": "Услуга: Тормозная система. стук при торможении",
  "source": "booking-form",
  "page": "https://example.com/",
  "sentAt": "2026-11-09T10:00:00.000Z"
}
```

Отзыв (`review`): `{ "type": "review", "name", "rating": 1–5, "text", "page", "sentAt" }`.
Отзывы не должны публиковаться автоматически: сначала модерация.

## 3. Варианты серверной части

| Вариант | Когда подходит |
|---|---|
| `examples/telegram-worker.js` (Cloudflare Worker) | Самый быстрый старт: заявка приходит в Telegram-чат мастерам. Бесплатно |
| Netlify / Vercel Function | Если сайт уже там. Тот же код, другая обёртка |
| Formspree, Web3Forms и подобные | Не нужен свой код. Проверьте, что сервис принимает JSON и отвечает 2xx |
| CRM (amoCRM, Bitrix24, HubSpot) | Через их вебхук или промежуточную функцию |

### Telegram за 5 минут

1. В Telegram напишите `@BotFather`, команда `/newbot`, сохраните токен.
2. Добавьте бота в чат мастеров, узнайте `chat_id` (например, через `https://api.telegram.org/bot<TOKEN>/getUpdates`).
3. Разверните `examples/telegram-worker.js` как Cloudflare Worker, секреты `TG_TOKEN`, `TG_CHAT_ID` и `ALLOWED_ORIGIN` (адрес сайта) задайте в настройках Worker.
4. Подставьте адрес Worker в `endpoints.lead`.

## 4. Защита от спама

- В формах уже есть скрытое поле-ловушка (`website`): бот, заполнивший его, отсекается на клиенте. Проверьте поле и на сервере.
- Ограничьте источник запросов (`ALLOWED_ORIGIN`) и частоту отправок с одного IP.
- Для высокого трафика добавьте Cloudflare Turnstile или аналог.

## 5. Юридически

Форма просит отдельное согласие на обработку персональных данных. Текст `/privacy` в шаблоне примерный:
замените его документом, составленным юристом по законодательству вашей страны.
